## 🎓 CGPA Calculator
This project is a user-friendly CGPA Calculator designed to help students compute their CGPA by entering course-wise grade details. Built using HTML, CSS, and JavaScript, it dynamically accepts input for any number of courses and computes the result instantly.

## ✨ Features
➕ Dynamic Course Input: Add any number of courses with respective grades.

📊 Accurate CGPA Calculation: Calculates based on user input using standard CGPA formula.

🖥️ Interactive Interface: Real-time updates and intuitive layout.

🎨 Modern UI: Styled with CSS for a neat and professional look.

📱 Responsive Design: Works seamlessly on desktops, tablets, and smartphones.

🧼 Clear/Reset Option: Easily reset the form to recalculate.

## ⚙️ Technologies Used
HTML5 – For input structure and layout.

CSS3 – For design and responsiveness.

JavaScript (Vanilla) – To manage input, logic, and calculations.
